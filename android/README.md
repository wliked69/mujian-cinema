# 幕间 · Android 1.2.1（测试版）

Android 8.0+ 客户端，连接电脑 / NAS 上的幕间网站，不是在手机上运行 Node 服务。账号、片库、评论和分类仍保存在服务器。**请使用更新后的网站与 App 1.2.1**。

## 安装与开始使用

1. 安装 `<本机导出目录>\幕间-Android-1.2.1-debug.apk`。与 1.2.0 使用相同包名和测试签名，可覆盖升级，不要先卸载以免丢失本机设置。
2. 若网站未启动，在电脑运行 `<项目目录>\start.cmd`；已运行则重新加载网页。
3. 管理员进入网站左下角「设置 → 服务与网络」，手动启用「允许局域网内访问」和「允许 App 搜索此服务器」，保存并重启服务。不会自动改防火墙、路由器或开放公网。
4. 手机与电脑在同一可信局域网。未配置服务器的 App 会自动打开设置并搜索约 7 秒；已登录可进入「设置 → 账号与登录 → App 连接设置」重新搜索；登录页也提供入口，连接失败时可点「更换服务器」。
5. 点搜索结果只会填入地址，**确认是自己的服务器后再点连接**。不会自动切换服务器、自动登录或发送账号密码到发现结果。
6. 使用现有账号登录并勾选「记住此设备」。App 保留网站 Cookie，不另外保存密码；管理员可撤销该设备会话。

手动地址示例：`http://192.168.1.10:3210`，替换成实际 IP / 端口；不要填写文件路径或账号密码。手机的 `127.0.0.1` 是手机自己；模拟器一般使用 `10.0.2.2` 连接电脑。

## 搜索范围与限制

采用固定 UDP 43210 的幕间发现协议，不逐个扫描 IP 或端口、不使用云端发现。App 只向已连接私有 IPv4 网络的广播地址发送两轮短请求，搜索最多约 7 秒、最多显示 20 个去重结果。离开页面、App 进入后台或关闭连接窗口即停止，不在后台持续扫描。

网站仅在允许局域网且允许 App 搜索时启用响应，只回应已知同子网的私有 IPv4 来源；返回固定服务名、实际网站端口和本次请求随机数，**不返回电脑主机名、用户名、影片列表、NAS 路径、Cookie 或令牌**。发现不是身份认证，请确认设备后登录。

- 老版网站（1.5.x 及更早）没有响应功能，需要升级并重启。
- 访客 Wi-Fi、无线隔离、不同子网、VPN 或防火墙可能阻止广播。搜索失败时仍可手动填写地址。
- 搜索目前基于 **IPv4 广播**；纯 IPv6 网络不自动发现。手动 IPv6 连接仍支持：`http://[fd12:3456::10]:3210`（格式示例）。公网 IPv6 使用 HTTPS；网站端须先启用 IPv6。
- Windows 防火墙可能需要你手动允许 Node 的专用网络 TCP 访问及 UDP 43210；本程序不创建规则。
- 当前 targetSdk 36，仅使用 INTERNET 网络权限；不索取定位、联系人、相机或麦克风权限，不扫描全部已安装应用。

## 手机外部播放器

进入 **设置 → 播放器设置 → 设置手机播放器**，选择：

- App 内置播放；或
- 手机外部播放器，再点「选择默认手机播放器」选择已安装且支持网络视频的应用，或每次由系统询问。

网站统一设置里的「播放器设置」在新版 App 中也提供「设置手机播放器」入口，不再让你选择电脑的 PotPlayer / VLC。电脑浏览器仍保留原来的 Windows 播放器设置；手机偏好仅影响当前手机。

点击电影封面或详情页的播放键会自动使用该设置；电视剧封面只开详情，**没有额外的“本地播放器”“继续观看”按钮**。底部原生工具栏已移除；返回使用安卓系统返回键或手势。

### 播放授权和兼容边界

- 本地 / NAS 视频：服务器签发只读、绑定当前一部影片 / 一集的临时地址，最长 6 小时；账号停用、改密码、撤销登录或退出后，新读取请求失效。服务器重启也会使旧临时地址失效，请重新点播放。
- 临时地址具有读取该视频的权限，**不要转发或公开**。它不是账号 / 管理令牌，不能读取其他集、评论或账户。每账号最多保留 8 个未过期播放地址。
- 手机播放器只接收视频地址，不接收密码、完整登录 Cookie、NAS 原始路径或任意 HTTP 请求头。
- API 视频使用可访问的 HTTPS 或可信内网 HTTP 直连地址。需要特殊请求头 / 认证 / 网页解析的线路不保证可用，不转发账号凭据。
- 只有幕间安卓 App 能选择外部手机播放器，手机浏览器使用网页内置播放。App 使用实际视频地址和视频类型匹配播放器；默认播放器不可用时尝试显示其他兼容播放器。播放器仍须支持网络播放并能解码该视频；只支持本地文件的系统相册播放器可能无法使用。没有兼容应用时会提示，可改回内置播放，不会自动安装第三方软件。
- 外部播放器的进度、选轨、字幕、下一集和返回结果取决于对应应用；**不保证回传 App 观看进度，不提供自动连播、服务器转码或 HDR 保证**。选集请先点片名进入详情。
- 需要较新的系统 WebView 支持受限消息通道。过旧时提示更新并保留内置播放，不使用高权限 `addJavascriptInterface` 回退。

## 点击规则

首页直接显示随机九宫格，打开或刷新首页重新抽取，不再显示大封面。**电影点封面直接播放；电视剧封面只开详情，再用编号方格选集并点播放，片名也只进详情**；进入详情不会自动播放。桌面网页现在也遵循相同规则。没有视频来源也可查看资料；演员、类别、片商等标签继续用于筛选。

## 折叠屏

保留原有外屏紧凑布局、展开自适应大屏、竖向铰链双区与横向半折控制区。视频全屏仍限制在安全区，旋转 / 折叠不主动重建 WebView。不报告折叠信息的设备按窗口宽度退回单区布局。App 进入后台暂停内置视频；不提供后台播放或离线下载。

## 安全与隐私

仅连接你信任的服务器。HTTP 不加密，仅在可信局域网使用，不要直接暴露到公网。HTTPS 证书错误直接拒绝，不忽略证书警告。文件访问、第三方 Cookie 和混合内容保持禁用，登录数据不备份 / 迁移。

原生消息通道仅允许配置的精确服务器来源和主框架，只提供读取手机播放器模式、打开播放器设置、打开连接设置、打开符合安全规则的视频四项操作；没有任意命令或文件读取功能。调试包可被已授权 ADB 检查 WebView，不要把 USB 调试权限交给不信任的电脑。

## 构建与验证

Java 17、Gradle 8.13、AGP 8.13.2、compile/target SDK 36、min SDK 26。使用当前已缓存依赖可运行：

```powershell
Set-Location <项目目录>\android
.\build.ps1 -UseGoogleMirror -Offline
```

默认 `build.ps1` 使用官方仓库；`-UseGoogleMirror` 显式使用公开 Google Maven 镜像，不改全局配置；1.2.1 使用已缓存依赖离线构建，未下载新依赖。原始 APK 位于 `app\build\outputs\apk\debug\app-debug.apk`。

构建 / 单元测试 / 静态检查结果见 `README.md`。**尚未真机验证局域网广播发现、Android 原生界面、实际外部播放器启动与解码、折叠切换**；浏览器消息桥模拟不等于真机通过。设备验收项目见 `DEVICE-QA.md`。

官方参考：[Android 视频 Intent](https://developer.android.com/guide/components/intents-common#Music)、[受来源限制的 WebView 消息通道](https://developer.android.com/reference/androidx/webkit/WebViewCompat)、[局域网权限](https://developer.android.com/privacy-and-security/local-network-permission)、[Node UDP](https://nodejs.org/api/dgram.html)。

## 多片库与权限（更新服务器后生效）

App 1.2.1 无需重新安装，重新加载服务器网页即可使用选库页；服务端权限逻辑需在电脑重启网站后生效。
管理员在网站的用户管理中分配片库与影片类别。多库账号先选库，再进入九宫格；顶栏“选库”可切换，单库自动进入。片商、系列、类别及演员标签会回到当前片库主列表，不在详情下方展开。

### 自定义影片库与电视剧选集

服务器更新后，管理员在“设置 → 影片库管理”自己建库、命名并勾选来源，不再一个来源对应一个库。用户管理中分配的是自定义库。
电视剧使用编号选集网格：详情中只选中不自动播放，按“播放”打开所选集；网页播放器内可通过网格切换集数。此为网页更新，App 1.2.1 无需重新安装；旧版折叠屏原生下一集控制仍保留兼容入口，未真机验证。
