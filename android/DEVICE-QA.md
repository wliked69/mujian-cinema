# 安卓设备验收清单（待真机执行）

以下不是已通过结果；用于安装后逐项验证。

## 准备

- 记录设备型号、Android 版本、System WebView 版本。
- 手机与服务端在同一可信局域网；先在手机浏览器确认片库地址可访问。
- 准备有权播放的 H.264 / AAC MP4、至少两集电视剧，以及带类别 / 日期 / 演员照片的资料。
- 使用测试账号；不要在问题截图中暴露服务器私密地址、密码、Cookie 或令牌。

## 连接、账号、后台

- [ ] 首次启动显示连接引导，未配置时不请求外部片库。
- [ ] 空地址、公网 HTTP、文件路径、含密码的地址不能保存；HTTPS 公网地址可设置。
- [ ] 错误地址显示重试 / 连接设置，改回正确地址可恢复。
- [ ] 使用已有账号登录，勾选记住设备，彻底关闭 App 再打开仍登录。
- [ ] 管理员在网页版登录设备中看到此安卓会话，可撤销；App 下次请求被要求登录。
- [ ] 普通账号无法访问管理界面，管理员可在网页统一设置管理用户、类别、网络与 AI 令牌。
- [ ] App 左下角「连接设置」能改服务器和清除本机登录；清除不删除影片或其他设备会话。

## 片库与播放

- [ ] 搜索、手动类别、点击演员看参演影片、演员照片、日期和评论正常。
- [ ] 随机九宫格是独立页面，返回键先关闭详情，再回上一页。
- [ ] 播放 MP4、有声、拖动进度、暂停；不出现重复播放器选择按钮。
- [ ] 电视剧集数正确，选集及下一集正常；没有下一集时按钮禁用。
- [ ] 全屏进入和退出，返回手势先退全屏，不直接退出 App。
- [ ] 切到后台暂停视频，回到前台由用户继续，不后台偷播。
- [ ] 断网显示适当提示，恢复后可以重试；图片缺失不导致崩溃。

## 折叠、旋转、多窗口

- [ ] 外屏竖屏：页面不超出窗口，登录表单和设置按钮可操作。
- [ ] 展开平屏：封面墙随宽度变化，当前页面 / 账号不重置。
- [ ] 竖向铰链：页面和播放控制两区分开，中间无可点按钮和被截断文字。
- [ ] 横向半折：视频在上安全区，控制区在下方，可滚动访问所有控件。
- [ ] 半折时全屏：视频不跨铰链；后退正常退出全屏。
- [ ] 播放中折叠 / 展开 / 旋转：不主动重载 WebView，进度不无故归零。
- [ ] 分屏拖窄、显示键盘、调整字体大小：重要控件可达，不被状态栏 / 导航条 / 键盘遮挡。
- [ ] 不报告折叠信息的设备：正常使用按窗口宽度适配的单区布局。

## 安全

- [ ] 不要求相机、麦克风、位置、联系人或文件权限。
- [ ] 不可信 HTTPS 证书拒绝连接，不能点击绕过。
- [ ] 外部 HTTP(S) 链接确认后才打开系统浏览器；不自动运行 intent / file 等链接。
- [ ] 系统返回键（旧安卓）和返回手势（新安卓）都可关闭网页详情 / 设置。

反馈格式：设备型号 / Android / WebView 版本 / 勾选失败的项目 / 最小复现步骤 / 脱敏截图。**未执行项保持未勾选。**

- [ ] 安卓 8–16 至少各选代表设备验证；不同厂商播放器及折叠屏没有在此清单自动视为通过。
