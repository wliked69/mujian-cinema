# 幕间影院 · Mujian Cinema

本地与 NAS 私人影视库：把电影、剧集、资料和账号权限放在自己的服务器上。

**Node.js 22+ · 无第三方 Node 运行依赖 · Windows 图形化管理 · Android 折叠屏客户端**

## 功能

- 本地文件夹、NAS 挂载目录及 JSON / 苹果 CMS 兼容 API 来源；可读取 NFO 与 TMDB 电影资料。
- 自定义影片库：自己命名，一个库包含一个或多个来源，来源也可以在多个库中共享。
- 管理员 / 普通账号；按账号分配影片库和类别，后端校验资料、图片、播放、评论及手机播放票据。
- 多库账号进入前选库，单库直接进入；首页随机九宫格，每次打开或刷新重新抽取。
- 3:2 封面、搜索、演员列表及照片、时长探测、日期、片商、系列、手动分类和评论。
- 电影点封面快速播放；电视剧点封面进详情，编号方格选集后再播放，不会自动播放。
- 片商、系列、类别、演员标签回主列表浏览，支持结果内搜索和分页。
- 账号登录设备管理、记住设备、可撤销会话；外观和影片列数按设备分别保存。
- 网页播放、Windows 外部播放器、Android 网络视频播放器；按设置统一选择。
- Windows 管理面板：启动、停止、重启、图形化后台及全站资料备份。
- 可配置端口、局域网访问、IPv6；Android 可搜索同一局域网中的服务器。
- 有限权限的本机 AI / 调试 API、OpenAPI 和 MCP stdio 工具；不提供任意命令执行接口。

## 快速开始

### Windows：图形化启动

下载源码后双击 `start.cmd`。首次启动会从源码编译 Windows 管理面板，再打开窗口。

管理面板会检测 Node.js：版本不足或未安装时，按项目已有机制从官网准备便携运行环境并校验下载，不修改全局 PATH。

> 需要 Windows PowerShell 5.1 / .NET Framework 编译管理面板。仓库不包含预编译 EXE、APK 或任何本机用户数据。

### 已安装 Node.js

```sh
git clone https://github.com/wliked69/mujian-cinema.git
cd mujian-cinema
node server.mjs
```

默认地址：<http://127.0.0.1:3210>。不需要 `npm install`。

首次使用在服务器本机创建管理员，**没有默认账号和密码**。服务默认仅本机可访问；从其他设备访问前，由管理员在「设置 → 服务与网络」配置并重启。

## 添加来源、建库与分配账号

1. 「设置 → 片库来源」添加本地 / NAS 文件夹或 API，扫描或同步。
2. 「设置 → 影片库管理」创建和命名影片库，勾选要包含的来源。
3. 「设置 → 用户管理」创建普通账号，选择允许访问的自定义库和影片类别。

来源和影片库不是一回事。例如，“家庭影院”可以同时包含客厅 NAS、卧室 NAS 和一个 API 来源。

片库与类别条件同时满足才可见；仅选择部分类型时，未分类影片不可见。“全部”包含以后新增的内容，取消“全部”且不选任何项表示不允许访问。

升级旧版本时，已有来源放进一个“默认片库”，可自行调整；旧账号按来源设置过的限制先保留，不自动扩大。以后新增来源不会自动归库。

## 电视剧目录

```text
片库/
└── 归档分类/
    └── 电视剧名/
        ├── tvshow.nfo
        ├── 第01集.mp4
        ├── 第02集.mp4
        └── ...
```

二级文件夹合并为一部剧，按文件名自然排序。详情与网页播放器使用编号选集网格；手机四列、宽屏六列，不显示会员角标。

## Android

Android 8.0+，连接已有服务端，支持外屏、展开大屏及折叠安全分区。

源码与构建步骤见 [Android 说明](android/README.md)。使用 Java 17、Android SDK 36 与 Gradle wrapper：

```powershell
cd android
.\build.ps1
```

手机播放器必须支持 HTTP / HTTPS 网络播放及对应编码。手机浏览器使用网页播放；在 Android 客户端中可选择外部播放器。实体折叠屏和第三方播放器需按 [真机验收清单](android/DEVICE-QA.md) 验证。

## 数据与备份

- 服务器数据保存在 `data/library.json`，包括账号哈希、会话、片库资料、收藏、进度、评论与设置。
- 缓存图片在 `data/` 内。NAS / 本地视频仍保留在原目录，不复制、不改名、不移动。
- Windows 面板提供整站资料备份；网页「影片备份」导出影片资料、库分组和可读取的缓存封面，不包含账号和视频。
- 搬迁视频目录请编辑原来源并使用「迁移目录（保留资料）」，不要删除来源后重新添加。
- **GitHub 仓库不是用户资料备份。不要把 `data/`、整站备份、API 凭据或签名密钥提交到 Git。**

## 安全与边界

- HTTP 只建议用于可信内网；本程序不自动修改防火墙，不应直接暴露管理端口到公网。
- 未获影片库权限的账号不能通过本站接口读取对应影片；已下载的数据不能撤回，已知外部直链和 NAS 自身权限不由本站控制。
- 默认按来源 IP 统计登录失败，10 次后临时限流 15 分钟。账号密码不能为空，不强制最小长度。
- AI 调试令牌默认只读、限本机、可撤销；不能管理账号或任意执行代码。令牌仅交给你信任的工具。
- 不包含服务器转码、自动连播、离线下载或任何电影正片；请只导入自己有权使用的视频。
- 当前仓库未额外授予开源许可证；公开可见不等于授予任意再分发许可。第三方资源遵守各自权利与条款。

## 验证

```sh
npm run check
```

测试使用独立临时片库和模拟 API，不读取真实 NAS。包括认证、访问隔离、目录扫描、HTTP Range、分类、评论、迁移、网络配置、播放器票据及自定义库。

Windows 专用检查仅在 Windows 上执行；Android 单元测试和 Lint 由 Android 构建脚本执行。浏览器操作通过不代表已完成真机解码验证。
