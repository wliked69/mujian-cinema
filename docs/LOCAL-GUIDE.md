# 幕间 · SCREEN ROOM

一个 Windows 本地运行的私人电影网站。**Node.js 22+，无第三方运行依赖，无需 npm install。**

## 启动

Windows 双击本目录 **`ScreenRoom.exe`** 打开「幕间 · 服务管理」，点击「启动服务」，再点「打开网站」或「打开管理后台」。面板可停止或重启它启动的服务，无需命令行。旧的 `start.cmd` 也会打开同一个面板。如果有旧版服务仍在运行，请先关闭它，避免端口冲突。

1.6.1 的两个打开按钮直接调用已安装浏览器；默认关联异常时可在面板的“浏览器”下拉框改选，或点击“复制地址”后手动粘贴到浏览器。不会改动系统默认浏览器。

- 自动检测 Node.js 版本，已有符合 `package.json` 要求的版本（当前为 22+）时直接使用，不强制升级。
- 未安装或版本过低时，从 **Node.js 官网**自动下载适配电脑架构的最新可用 LTS，校验 SHA-256 和官方发布者签名后，放在项目的 `.runtime` 目录中启动。
- 不需要管理员安装权限，不替换系统 Node，不修改注册表或全局 PATH。首次下载需要联网；缓存有效时可离线启动。失败会显示原因，不会绕过校验继续运行。
- `.runtime` 是可重新下载的运行环境，不是用户数据，迁移时可以不复制。此自动准备流程和桌面面板仅适用于 Windows；其他系统需要自行准备 Node.js 22+。
- 网页后台需要管理员登录，仍可从站内左下角「设置」进入。保存端口、IPv6 或局域网设置后，在桌面面板点击「重启服务」生效。点面板右上角 × 会停止它启动的网站并自动退出；有正在保存的工作时先关闭网络连接，再等待工作完成。需保持运行请最小化。
- 片库、首页九宫格、影片详情和资料匹配使用 3:2 横版封面；原图居中裁切显示，不拉伸也不修改图源。演员头像比例保持不变。
- 「设置 → 影片备份 → 下载影片备份」可一键下载 `.tar.gz`。其中 `movies.json` 保存当前正式片库的影片资料、手动分类与资料、剧集和本地路径，`covers/` 包含片库引用且可读取的服务端缓存封面，`manifest.json` 列出打包结果。不会下载外部图片、复制 NAS 原图/视频、导出账号/令牌/观看记录或外部播放地址。备份不是全站镜像，目前不提供一键导入。完整迁移仍需另外备份正式 `data/` 和 NAS 文件。
- 「设置 → 外观与主题」的主题、颜色、每行影片数保存在当前浏览器或 App，同一账号在其他设备可单独设置。没有本机设置时沿用原账号外观；清理网站数据会清除本机外观。影片列数可选自动或 1–8 部，手机窄屏最多两列，保留 3:2 封面和随机九宫格。
- 手机窄屏把原左侧导航移到底部，顶部保留搜索和「演员」入口，影片区占满内容宽度；桌面宽屏布局不变。现有安卓 App 连接服务器并重新加载页面即可使用。
- 搬迁 NAS / 本地文件：先在桌面面板备份，再把视频、同目录图片、NFO 和演员图片按原相对路径搬到新目录。管理员进入「片库来源」编辑原来源，改路径后点「迁移目录（保留资料）」。网站核对已登记的文件和图片，不搬动任何文件；迁移后保留影片及选集 ID，重扫继续沿用。不要删除旧来源、改相对路径或用不同影片替换同名文件。
- 「一键备份网站资料」在 Windows 面板将 `data/library.json` 和缓存封面保存为 ZIP，包含账号、片库、收藏、进度、评论、来源及网站配置。备份含账号信息与网站配置内的访问凭据，需私密保管；不包含视频、NAS 配套文件、其他本机工具的令牌文件或日志。恢复前关闭网站并另存现有资料，再将 ZIP 内的 `data/` 内容按原路径放回项目。
- 「全部影片」默认按本地视频文件修改时间倒序，剧集取最近修改的一集，演员列表取其参演影片中最新的时间；旧片库需重扫一次以补齐。没有本地文件时间的条目以已有资料更新时间或入库时间作备用。

如果终端中已经有符合要求的 Node.js，也可在本目录运行：

```powershell
npm start
```

只检测环境、不下载也不启动服务：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\bootstrap-node.ps1 -CheckOnly
```

只准备运行环境、不启动服务，将 `-CheckOnly` 换成 `-InstallOnly`。项目内的 Node 不会变成全局 `node` 命令；外部 AI / MCP 工具若找不到 Node，请将其命令配置为检测结果中 `Path` 指向的 `node.exe` 完整路径。

默认访问地址为 <http://127.0.0.1:3210>。首次使用先创建管理员，**没有默认账号和密码**。如使用命令行启动，按 Ctrl+C 停止。服务默认只监听 `127.0.0.1`。管理员可在「左下角设置 → 服务与网络」更改端口和网络访问，保存后重启生效。默认不会对局域网开放，也不会修改防火墙。

若端口被占用：

```powershell
$env:PORT = '3211'
npm start
```

## 接入 NAS

1. 先在 Windows 资源管理器中打开并登录共享，或映射网络驱动器。
2. 管理员登录网站，进入「左下角设置 → 片库来源 → NAS / 本地文件夹」。
3. 填写 `Z:\电影` 或 `\\192.168.1.20\movies`，点击「保存并扫描」。
4. 等待页面显示扫描结果；新增、移除文件后手动重新扫描。

网站使用**启动 Node.js 的 Windows 账户**的文件访问权限，不保管 SMB 密码，不负责系统级挂载，不安装 NAS 服务。若从 Windows 服务或其他账户启动，可能无法看到你登录会话中的映射盘；使用该账户有权限的 UNC 路径。**尚未验证你的真实 NAS 连接，需要你提供路径后再检查。**

推荐目录（按你确认的二级目录规则）：

```text
片库/
├─ 电影/
│  ├─ 星际穿越.2014.mp4
│  ├─ 星际穿越.2014.nfo
│  └─ poster.jpg
└─ 剧集/
   └─ 电视剧名称/
      ├─ tvshow.nfo
      ├─ 第1集.mp4
      ├─ 第2集.mp4
      ├─ 第3集.mp4
      └─ .actors/演员姓名.jpg
```

视频位于「片库／归档分类／电视剧名／视频」时，二级文件夹合并为一部电视剧。普通电影请直接放在片库根目录或一级归档目录；把电影放进二级目录也会按你指定的规则识别为电视剧。

**文件夹归档和影片类别已分开。**

- 文件夹归档：使用片库下一级文件夹名称，根目录视频使用根目录名称；来源可设置归档分组别名。首页「文件夹归档筛选」单独筛选，不会写入影片的「类别」。
- 影片类别：管理员在详情或网页播放页点击「编辑类别」，自由填写多个标签，也可全部清空；缺失时内容留空。NFO/API/TMDB 可以提供初始资料类别，手动设置（包括清空）优先，重新扫描或匹配资料不会覆盖。点击类别只匹配同标签影片，不按文件夹判断。
- 「恢复资料类别」移除手动覆盖，恢复最近读取的 NFO/API/TMDB 类别，绝不会恢复为文件夹名称。
- 旧版仅自动带入的文件夹类别会移至独立归档信息；原有手动类别保留。升级不改名、不移动视频或 NFO。首次按新版本启动时在内存升级索引，之后正常保存数据时持久化。


海报：`片名-poster.jpg`、`片名.jpg`、`poster.jpg`、`folder.jpg`、`cover.jpg`；也支持 jpeg/png/webp。背景：`fanart.jpg`、`backdrop.jpg`。NFO：同名 `.nfo` 或 `movie.nfo`。文件名也用于推断标题和年份。不下载 NFO 内的外部 URL，不处理外部 XML 实体。

扫描只读原目录，不复制视频、不改名、不移动、不删除原文件；跳过符号链接/隐藏目录，限制 12 层、每个来源 20000 部视频和 100000 个普通文件。NAS 断开或 API 同步失败时保留该来源的旧索引。部分子目录无法读取会显示警告，该次成功扫描会按实际可读目录重建索引。

## API 资料与演员信息

### TMDB（推荐）

在 [TMDB 账号 API 设置](https://www.themoviedb.org/settings/api) 获取 **API Read Access Token**。在网站「左下角设置 → 片库来源 → API 接口」选择 TMDB，填写令牌，**仅保存**即可供 NAS 影片匹配使用。

打开 NAS 影片详情 →「匹配资料」→ 输入或修正中英文片名 → 确认候选影片，即可导入演员、导演等资料。**搜索会将片名发送给 TMDB，不发送视频、NAS 地址、账号密码。**需要能连接 TMDB 的网络。没有令牌时仍可读取本地 NFO/海报。

选择「保存并同步」则导入 TMDB 热门电影的资料，**不含正片**。TMDB 资料不是播放源或播放授权。

官方资料：[搜索与详情](https://developer.themoviedb.org/docs/search-and-query-for-details)、[电影详情](https://developer.themoviedb.org/reference/movie-details)、[图片 URL](https://developer.themoviedb.org/docs/image-basics)。

### 通用 JSON

提供 GET 接口，返回数组，或 `{ "movies": [] }`、`{ "list": [] }`、`{ "results": [] }`、`{ "data": { "list": [] } }`。多页时使用 `page` 参数。

```json
{
  "movies": [
    {
      "id": "movie-001",
      "title": "示例电影",
      "originalTitle": "Example Movie",
      "year": 2024,
      "genres": ["剧情", "冒险"],
      "poster": "https://your-server.example/poster.jpg",
      "overview": "电影简介",
      "director": "导演姓名",
      "cast": ["演员一", "演员二"],
      "rating": 8.5,
      "streams": [
        { "name": "正片", "url": "https://your-server.example/authorized-movie.mp4" }
      ]
    }
  ]
}
```

只接入你信任且有权使用的接口。图片与视频需要绝对 HTTP(S) URL。可选 Bearer Token 仅用于服务端 API 请求；不会转发给图片或视频域名。需要认证的视频链接需提供可直接访问的授权链接。本版不支持任意自定义请求头。

### 苹果 CMS 兼容 JSON

配置 JSON 接口地址；服务器请求 `ac=detail&pg=页码`，适配 `vod_name/vod_pic/type_name/vod_actor/vod_director/vod_play_url` 等字段。仅支持直连媒体，不加载第三方解析网站，不执行接口返回的 HTML 或脚本。

## 用户权限

| 能力 | 管理员 | 普通用户 |
|---|---|---|
| 浏览、搜索、播放 | ✓ | ✓ |
| 独立收藏、观看进度、修改自己密码 | ✓ | ✓ |
| NAS 路径、API 配置、扫描与匹配 | ✓ | — |
| 用户创建/角色调整/停用/密码重置 | ✓ | — |
| 调试令牌和诊断 | ✓ | — |

无公开注册。统一从左下角「设置」进入；管理员在设置中心左侧直接看到用户管理、登录设备管理、片库来源、服务与网络及 AI / 调试接口。普通用户无法直接通过 HTTP 绕过后端授权。不能降级或停用最后一个有效管理员。角色/状态/密码/影片访问权限修改会使该用户的现有会话和调试令牌失效。默认勾选「记住此设备」：同一浏览器的登录可跨页面、浏览器及服务重启保留，90 天有效，并在使用时按天续期；不保存明文密码。不勾选时使用临时浏览器 Cookie，服务器端最长 1 天。退出登录、清理 Cookie、更换浏览器/地址、密码或角色变更、账号停用、管理员撤销该设备后需重新登录。登录错误 10 次后临时限流 15 分钟。

密码不设置最小或最大字符长度，可以使用单字符密码；仅要求不能为空。首次设置、创建用户、重置密码和修改自己密码都遵循同一规则，旧密码仍然有效。请求整体仍有 1 MB 的通用大小限制，防止异常请求耗尽服务资源。短密码更容易被猜到，请保持本机访问，不要将服务暴露到公网。

密码使用带随机盐的 `scrypt` 哈希；会话 Cookie 为 HttpOnly + SameSite=Strict；调试令牌只显示一次，服务器只保存 SHA-256 哈希。TMDB/来源访问令牌因需要发起请求，保存在本地数据文件中，不是加密保管库。

## 后台调试 / Codex

左下角「设置 → AI / 调试接口」创建令牌。默认只读、短期有效，可随时撤销。

| 令牌权限 | 可调用能力 |
|---|---|
| `read` | 脱敏片库查询、扫描状态、诊断、审计、TMDB 搜索 |
| `classify`（AI 分类专用） | 仅片库查询、任务状态、OpenAPI，以及单片/批量分类调整 |
| `write` | read 全部能力，另可扫描、确认导入资料、调整分类 |

调试令牌均仅供服务器本机调用，不能管理用户/登录设备、创建新令牌、改网络、读写评论、修改个人偏好、启动播放器或执行系统命令。令牌查询不返回视频/海报链接、NAS 路径、账号偏好或收藏；分类专用令牌也不允许诊断、审计或向 TMDB 搜索。

### CLI / REST

将令牌安全地放进当前进程的 `SCREENROOM_TOKEN` 环境变量；不要把真实令牌提交到仓库、贴进聊天或放在 URL 中。下面命令均不包含真实密钥：

```powershell
# 先通过本机安全方式设置 SCREENROOM_TOKEN 环境变量，再运行：
node scripts/admin-client.mjs diagnostics
node scripts/admin-client.mjs movies 诺兰
node scripts/admin-client.mjs sources
node scripts/admin-client.mjs job
node scripts/admin-client.mjs audit
node scripts/admin-client.mjs match <movieId> "Interstellar"
```

非默认端口可设置 `SCREENROOM_URL=http://127.0.0.1:3211`。客户端拒绝远程地址和 HTTP 重定向。CLI/MCP 写操作还需显式设置 `SCREENROOM_ALLOW_WRITE=1`。扫描/资料导入需要 write；分类调整可用 classify 或 write 令牌：

```powershell
node scripts/admin-client.mjs scan <sourceId>
node scripts/admin-client.mjs enrich <movieId> <tmdbId>
node scripts/admin-client.mjs genres <movieId> 科幻,待看
node scripts/admin-client.mjs genres-reset <movieId>
# JSON 方案从 stdin 读取，默认只预览；追加 --apply 才提交
Get-Content -Raw -LiteralPath .\classification-plan.json | node scripts/admin-client.mjs genres-batch
```

REST 使用 `Authorization: Bearer <调试令牌>`，OpenAPI 在登录后访问 `/api/openapi.json`。诊断在 `/api/admin/diagnostics`，审计在 `/api/admin/audit`。诊断不包含 NAS 路径、密码或 API 令牌。审计记录操作人/时间/动作，不记录请求正文、密码、Cookie 或访问令牌。最多保留 500 条审计事件。

### MCP stdio 桥接（可选）

## 播放限制

内置 HTML5 播放器，支持本地文件 Range 拖动和进度恢复。MP4/H.264/AAC、WebM 通常兼容；实际由浏览器与编解码器决定。MKV/AVI/HEVC/DTS/部分 HLS 可能无法在浏览器中播放，**无转码、无外部解析、无网页外挂字幕、电视剧按指定的二级文件夹规则聚合（见下文）**。检测和传输接口已测试，但未覆盖每一种视频编码。

### 交给设备上的播放器

左下角「设置 → 播放器设置」保存默认播放方式和播放器，之后影片详情仅显示一个「播放」按钮，自动采用偏好；不再显示独立的本机播放器或继续观看按钮。网页模式会自动恢复已有进度。

- **本地/NAS 视频**：支持系统默认播放器，或常规目录安装的 PotPlayer / VLC。直接把已经导入、且处于授权片库目录内的文件交给播放器，绕过浏览器编码限制；不修改系统关联。
- **API 网络视频**：可选择 PotPlayer / VLC 和具体线路；只发送该影片已有的 HTTP(S) 授权视频链接，系统默认方式不用于打开网络视频，以免重新跳回浏览器。
- **设备范围**：启动的是运行 Node.js 服务的这台 Windows 电脑上的播放器。不是在远端手机、电视或 NAS 主机启动，也不是投屏。只有从服务器本机访问时允许启动外部播放器；局域网设备强制使用网页播放，不允许远程弹出服务器播放器。
- 需要播放器已安装，且启动网站的 Windows 账户能访问 NAS 文件。便携版或非标准目录安装的播放器可能无法自动发现，可使用系统默认播放器，或由管理员复制路径手动打开。
- 外部播放器是否能解码由它自身决定；外部播放进度暂不回传网站，也不自动恢复网页进度。启动接口返回成功仅表示已发出打开请求，不代表视频已成功播放。默认播放方式和播放器统一在左下角「设置 → 播放器设置」中保存，以后点击播放直接采用该偏好，不再每次弹出选择器。
- 启动需登录、同源操作，并限制重复点击；调试令牌和 MCP 不允许调用此启动接口。不提供任意程序路径、任意命令或任意文件的执行能力。

## 图形化设置与管理（v1.5.0）

### 个人设置

左下角固定的「设置」供所有登录用户使用；短屏时只有其上方导航滚动，不会把设置挤出屏幕。设置中心左侧直接切换页面，无需在页底寻找后台链接。可修改默认播放方式、默认本机播放器、深色/明亮/跟随系统主题，以及全站主题色。背景、侧栏、顶栏、卡片、弹窗、表单和按钮同步换色，文字对比度自动适配；海报图片保持原样。支持预设配色和即时预览，点击保存后写入当前账号，保存不会关闭设置；关闭会取消未保存预览，其他用户不受影响。网页播放与外部播放的切换不改变系统默认应用。

### 登录情况

管理员在「左下角设置 → 登录设备管理」查看所有用户的最近登录、最近活动、登录设备、来源 IP、有效会话以及成功/失败记录，也可以退出指定设备。在线表示近 3 分钟有请求或心跳，页面可见时每分钟发送心跳，后台面板每 15 秒刷新；不是精确的窗口开关检测。设备名称根据浏览器声明的 User-Agent 推断，不是硬件身份认证。IP 直接取连接来源，不信任 X-Forwarded-For。只记录必要的设备/时间/IP 与结果，不记录密码或原始 Cookie。

同一设备的不同浏览器、隐私模式、不同网站主机名（例如 localhost 与 127.0.0.1）分别保存 Cookie，可能需要各登录一次。正常关闭页面不会注销「记住的设备」。服务端只持久化随机会话令牌的哈希，Cookie 为 HttpOnly + SameSite=Strict；仍须保护整个 data 文件夹。

### 服务与网络

「左下角设置 → 服务与网络」可设置 1–65535 的端口号和是否允许局域网访问。**保存后点击桌面面板中的「重启服务」，当前连接不会在保存时立即中断。** 页面显示当前运行配置、待生效配置与访问地址。PORT 环境变量优先于界面端口设置，若要使用界面设置请先移除该环境变量。

管理员也可在同一页底部点击「关闭网站」，再点「确认关闭网站」。关闭会断开所有设备和正在播放的视频；需要时请在服务器上的启动器中点「启动服务」。扫描、迁移或网页备份期间暂不接受关闭请求。此按钮只接受当前网站的管理员登录会话，不接受普通用户、调试令牌或跨站请求。

默认关闭网络访问与 IPv6，仅绑定 `127.0.0.1`。开启网络访问后，IPv4 绑定 `0.0.0.0`；额外启用 IPv6 时，同时增加独立的 IPv6-only 监听：仅本机模式绑定 `::1`，网络模式绑定 `::`。IPv4 和 IPv6 使用相同端口；不依赖系统自动双栈行为。IPv6 开关独立，保存后手动重启生效，默认不会替你开启。

所有网络接口可能包含 VPN / 公网网卡。网络访问必须勾选风险确认；向网络新增 IPv6 监听还需额外确认，因为**公网 IPv6 可能不需要路由器端口映射就能被访问**。本程序不会修改防火墙、添加路由器端口映射或注册系统服务。实际可达性取决于系统防火墙、路由和网络隔离。HTTP 不加密，公网 / 不可信网络需要另外部署 HTTPS。首次管理员仍要求在服务器本机创建。

网络访问开放后仍要求账号登录，管理接口仍要求管理员权限。Host 白名单只接受本机环回地址、已知网卡地址或机器主机名；启用 IPv6 后识别压缩 / 展开的等价 IPv6 地址，不接受任意 IPv6 地址、伪造域名、凭据和带接口标识的 Host。调试令牌及 Windows 外部播放器仍仅供服务器本机调用，IPv6 远端设备不会因此获得本机权限。

管理员进入「左下角设置 → 服务与网络」，勾选「启用 IPv6（保留 IPv4）」并保存、手动重启。仅本机模式可访问 `http://[::1]:3210`；跨设备还需允许网络访问，并使用后台列出的 IPv6 网络地址。IPv6 URL 必须保留方括号，例如 `http://[fd12:3456::10]:3210`（仅格式示例，替换为实际地址与端口）。后台显示当前生效协议、已保存配置与重启提示。

不为 `fe80::/10` 链路本地地址生成浏览器链接，因为需要客户端接口标识且常用浏览器 / Node URL 不兼容此类带区号 URL；跨设备请使用可路由 ULA 或全局 IPv6 地址。IPv6 不可用或端口冲突时会清理已启动的监听并明确报错，不会假装启用成功。若系统不支持 IPv6 导致无法启动，可将 `data/library.json` 中 `network.enableIpv6` 改为 `false` 后重启（不要改账号等其他字段）。

安卓 App 1.0.0 已能填写带方括号的 IPv6 地址，不必为了网站修复重新安装；HTTP 仅允许内网 / 私有 IPv6，公网 IPv6 需要 HTTPS。尚未替你配置 HTTPS 或验证跨设备 / 公网连通性。实现依据：[Node 监听选项](https://nodejs.org/api/net.html#serverlistenoptions-callback)、[网卡与 scopeid](https://nodejs.org/api/os.html#osnetworkinterfaces)。

## 外部 AI 分类接口

不是只有占位接口：REST、CLI 与 MCP 均已用独立测试片库实际调用。尚未将你的 Codex 或其他外部 AI 客户端连接到正式片库。建议先在设置中创建短期 **AI 分类专用**令牌，只通过本机环境变量交给指定客户端。

1. `GET /api/library` 获取影片 ID 和当前 `genres`。示例资料不可编辑，需先导入自己的影片。
2. 单片：`POST /api/movies/{id}/genres`，正文如 `{"genres":["科幻","待看"],"expectedGenres":["旧分类"]}`；恢复资料类别用 `{"reset":true}`。
3. 批量：`POST /api/movies/genres/batch`，先预览：

```json
{
  "dryRun": true,
  "updates": [
    { "id": "从片库读取的影片ID", "genres": ["科幻", "待看"], "expectedGenres": ["旧分类"] }
  ]
}
```

默认 `dryRun=true`，只返回修改前后方案，不改分类。确认后使用相同 updates 并明确 `dryRun:false` 提交。每批 1–100 部；重复 ID、缺失影片、非法分类或任一 `expectedGenres` 冲突都会拒绝整批，不会部分提交。冲突返回 HTTP 409，需重新读取；建议 AI 每次提交均附带预览时读取的 expectedGenres，避免覆盖其他人的修改。read 令牌不能写分类。每片 0–12 个类别（空数组代表明确清空），每个最多 40 字。

手动分类扫描后保留，不移动文件、不改目录或 NFO。MCP 开启写工具仍需 `SCREENROOM_ALLOW_WRITE=1`；创建令牌和开启工具不等于已经安装或连接外部 AI，也不会自动代你做分类。

## 影片资料字段与评论

影片详情和网页播放器下方都有 **时长 / 日期 / 片商 / 系列 / 类别 / 演员**。时长和日期不提供点击筛选；类别、片商、系列、演员可以点击，展示片库内同一值的其他影片（不含当前影片），不跳去外站，不打断当前视频；相关卡片可打开详情。按完整名称匹配而不是包含子串。找不到其他同类影片时明确提示。**缺失资料仅保留字段名，内容留空，不显示占位文案、不编造。**

- NFO：`runtime`、重复 `studio`、`set/name` 或 `series`、`genre`、`actor/name`。类别与文件夹归档独立；手动填写/清空优先于资料类别，和主片库类别筛选一致。
- 通用 JSON：`duration`、`studios`（名称数组）/`studio`、`series`（名称数组或字符串）、`cast`（姓名数组或字符串）。也兼容 `production_companies`、`belongs_to_collection` 及 `vod_studio/vod_producer/vod_series/vod_actor`。
- TMDB 确认资料后读取 production_companies / belongs_to_collection；热门资料列表未包含这些字段时保持空白。
- 管理员可在详情/播放页「编辑日期 / 片商 / 系列 / 演员」中补全或清空；手动资料扫描和重新匹配后保留，不改 NAS 原文件。手动分类仍通过「编辑类别」单独调整。

评论对片库内所有登录用户可见，仅保存到本机 data/library.json。支持换行，按纯文本显示，不执行 HTML/脚本。用户可删除自己的评论，管理员可删除任意评论；删除前有确认，删除不可恢复。不提供匿名发布或外部同步。

每条 1–2000 字，每个用户发送间隔至少 3 秒；每部最多 500 条，全库最多 10000 条；每页 50 条，可加载更早评论。读取、发表与删除均要求浏览器登录会话，调试令牌/MCP 无权限。评论只显示作者昵称和时间，不公开 IP、账号 ID、密码或登录设备。真实 NAS、TMDB 及外部 AI 连接仍需用户配置后实测。

## v1.5.0：独立九宫格、时长、演员、日期与电视剧

### 随机九宫格首页

「首页」直接显示九宫格，没有精选大图。每次打开或刷新首页重新抽取，打开详情不重新抽取。「全部影片」中的「随机抽 9 部」仍可进入 `/random` 按当前条件抽取。网页和 App 点电影封面直接播放；电视剧封面和片名只进入详情，在详情中选集再播放。

### 自动读取时长

本地/NAS **重新扫描**时只读容器元数据，自动识别常见 MP4/M4V/MOV（mvhd）与含 Duration 信息的 MKV/WebM（Segment Info）；不解码整部视频、不改写原文件。损坏、缺失或超出读取限制的元数据不猜测，保留 NFO/API 已有时长或空白。API 影片可直接提供 `durationSeconds`，单位秒。

如果系统已安装 ffprobe 并位于 PATH，或启动前配置 `SCREENROOM_FFPROBE` 为其可信程序路径，其他支持格式可使用限时 5 秒的本地探测；只允许文件协议及限定容器格式，不接受网页指定程序路径，不自动安装 FFmpeg，也不支持远程 URL 探测。当前开发机器未检测到 ffprobe，MP4/MOV/MKV/WebM 的内置读取已测试，ffprobe 的真实运行未验证。

封面鼠标悬停/键盘聚焦时在右下角显示时长（`MM:SS` / `H:MM:SS`）；触屏默认显示。未知时长不显示虚构数值。详情里的时长为普通文字，不能点击筛选。电视剧仅在全部集数均有可靠时长时显示总时长，否则不推算全剧时长。

格式参考：[Apple mvhd](https://developer.apple.com/documentation/quicktime-file-format/movie_header_atom)、[Matroska Duration/TimestampScale](https://www.matroska.org/technical/elements.html)、[ffprobe 官方说明](https://www.ffmpeg.org/ffprobe.html)。

### 右侧演员列表

桌面右侧显示演员头像、姓名、片库参演数量，支持搜索和展开更多。点击演员后，主片库顶部显示该演员的大头像、姓名和参演数量，下方可搜索该演员的全部片库影片及剧集。清除筛选后隐藏头像区。手机窄屏点顶部「演员」展开列表。

- 通用 JSON 可提供 `actors: [{"name":"演员姓名","photo":"https://可信地址/portrait.jpg"}]`，兼容 `avatar/thumb`；非法协议拒绝。
- 手动修改：在影片所在目录（电视剧在剧名目录）打开或创建 `.actors`，放入或替换 `演员姓名.jpg`。文件名需与同目录 NFO 中的演员姓名一致，支持 jpg/jpeg/png/webp；空格也可写成下划线。重扫对应来源后刷新页面；若旧图片仍被缓存，可强制刷新。多个影片使用同一演员的本地图时，优先使用较新影片关联的图片。网页和 MCP 暂不支持直接上传演员头像。
- NFO 还支持 HTTP(S) 的 `actor/thumb`，TMDB 匹配可读取演员 `profile_path`。本地图优先；没有照片时用占位符，不用影片海报充当头像。照片文件必须位于已授权片库内，不向网页或 AI 令牌返回磁盘路径。
- 手动修改演员姓名会保留同名已知照片，新姓名没有照片时保持空白。

参考：[TMDB Credits](https://developer.themoviedb.org/reference/movie-credits)。本轮未使用真实访问令牌验证在线查询。

### 日期

详情/网页播放页显示上映或发行日期。读取通用 API `releaseDate/release_date/premiered/vod_pubdate`、NFO `premiered/releasedate`、TMDB `release_date`。管理员可在「编辑日期 / 片商 / 系列 / 演员」中保存或清空；严格校验有效 `YYYY-MM-DD`，不会把仅有的年份拼成虚假日期。手动日期重扫/匹配后保留。

### 电视剧集数与播放

扫描把「片库／归档分类／电视剧名／视频文件」中每个二级文件夹合并为一张电视剧卡片，并显示「共 N 集」。每个支持的视频文件算一集，按文件名自然排序（第2集在第10集前）；剧名目录下的更深季目录也归入这部剧。花絮/预告也会计数，若不应当作集数，请将其移出该电视剧目录。单个文件也可显示共 1 集。

剧名和资料优先读取剧名目录内 `tvshow.nfo`，没有剧名资料时使用文件夹名。详情可以选集，网页播放器可随时切换集数；本机播放器也会打开已选的集数。观看记录包含集数，避免将上一集进度套用到另一集。电视剧暂不使用电影专用 TMDB 匹配接口，可用 tvshow.nfo 或自己的资料接口；没有实现在线补全全剧季/集数据库、自动连播或转码。

按新规则重新扫描旧散集索引时，尽量合并保留原有手动类别、收藏、最近单集进度和评论；原文件不移动、不改名。原有文件夹归档仍与自定义影片类别独立。需要先停止旧服务、启动新版本，再重新扫描来源才能识别现有视频时长及电视剧集数。

首页/侧栏「让好电影，有个家。」宣传区已移除，设置入口仍固定左下角。

## 手机发现、手机播放器与详情播放

- 网页和安卓 App 均为点电影封面直接播放；电视剧封面只进详情选集，片名只进详情，进入详情不自动播放。
- 网站「设置 → 服务与网络」新增「允许 App 搜索此服务器」，默认为允许，但仅在已手动允许局域网时启动 UDP 43210 响应；只回应同一 IPv4 子网内的私有来源，不发送账号、电脑主机名或片库信息。不自动改防火墙。
- App 未配置时自动搜索约 7 秒，已配置可在「设置 → 账号与登录 → App 连接设置」重新搜索；发现结果只填地址，需要用户确认连接，不自动切换。纯 IPv6 / 广播隔离网络仍需手动地址。此发现协议是幕间专用 UDP，不是通用 NAS / SMB / mDNS 扫描。
- 手机播放器与电脑播放器分开设置；App 内的网页统一设置提供手机入口，不再显示 Windows 播放器选项。底部原生连接设置与返回按钮不再显示，保留系统返回键 / 手势。手机网页搜索栏仅保留必要的安全区与触控高度。
- NAS / 本地视频外部播放使用绑定单片 / 单集、最长 6 小时的临时 URL，不交出密码、登录 Cookie 或 NAS 路径；失效后重新点击播放。账号停用、改密码、退出或撤销会话后，下一次读取失效。不要公开临时链接。
- 播放 URL 不属于外部 AI API；调试令牌不能签发手机播放地址。视频仍要求当前文件位于已授权片库，移除集数不会回退成其他集。
- 更新 App 并重新加载新版网站后使用。外部播放器需支持网络视频，进度回传 / 编解码不保证；没有真机自动发现或外部播放器测试结果。详见 [App 说明](android/README.md) 和 [验证记录](docs/QA.md)。

## 多片库、账号访问范围与选库页

- 「片库来源」只表示 NAS、本地目录或 API 的数据来源，最多 10 个；影片库是单独创建和命名的分组，最多 100 个。先在「设置 → 影片库管理」建库并勾选一个或多个来源，再到「用户管理 → 编辑 → 影片访问权限」为账号勾选影片库和类别。
- 片库范围与类别范围同时满足才可见；类别匹配任意一个已勾选标签。这里使用影片可手工编辑的类别，不是文件夹归档。仅选部分类别时，未分类影片不可见。
- “全部片库/全部类别”包含以后新增内容；取消“全部”却不选择任何项，表示不允许访问。旧账号和未指定范围的新账号保留原来的全部可见行为，需管理员主动限制。管理员始终可见并管理全部片库。
- 有多个可见片库时，从根地址进入先显示选库页。可进入某一个库，也可选择“全部可见片库”；只有一个库时直接进入。顶栏“选库”可切换，搜索、演员、九宫格和标签浏览都在当前选择内。
- 所选片库写在当前页面 URL 中，不保存为账号全局偏好；直接打开带有效片库参数的链接或刷新会保留当前选择。失去权限的片库链接不能恢复访问。
- 后端过滤资料、历史及来源数量，并在本地视频、图片、评论、收藏、进度、本机启动和 App 播放票据读取时校验权限。AI 调试令牌仍不能管理账号或修改账号范围。
- 保存用户后该用户需重新登录，旧手机播放 URL 的后续请求也会失效。已经发送或下载到设备的内容不能撤回；已经建立的传输不会被本功能远程清除。外部 API 视频的原始直链、NAS/操作系统权限不受本站账号限制控制，不可把这些地址当成网站授权。
- 权限与账号一同保存在服务器 data/library.json；桌面面板的整站备份包含这些设置，网页“影片备份”不包含账号。
- 网页和 App 的电影封面直接播放；电视剧封面只进详情，选好集数再点播放。片名始终只进详情。详情内点击片商、系列、类别或演员，会关闭详情，转主列表展示同标签影片；支持该结果内的小搜索、分页与刷新，不再在详情下方堆叠同类影片。
- 本次需要手动重启网站服务，再刷新网页 / 重新加载 App 页面。没有原生安卓改动，不需要重新安装 APK。

## 自定义库分组与方格选集

- 数据来源和影片库不再一一对应。“家庭影院”可以同时包含客厅 NAS、卧室 NAS 及 API 来源；来源也可被多个库共享。分组不移动文件、不重新扫描，也不改影片、剧集或收藏 ID。
- 新增、改名和归入来源在「设置 → 影片库管理」操作。每次保存带版本号，过期编辑会被拒绝以避免覆盖其他管理操作。移除库只删除分组，不删除来源、影片资料或文件。
- 首次升级时，已有来源统一归入一个“默认片库”，不会按来源自动拆库。管理员可自行编辑或重新建库。以后新增来源不会自动归库，未归库来源只有管理员可见。
- 旧版按来源设置过的账号会继续保留原来源限制，与新库范围取交集，不自动扩大。管理员编辑账号时可显式勾选“确认用自定义影片库权限替换旧来源限制”再保存；请先核对库内来源。
- 调整库内来源后，普通账号的资料和后续媒体请求立即按当前分组重新校验；已发送的数据不能撤回。账号本身权限保存后仍需重新登录。自定义库及来源映射保存在 data/library.json，也包含在网页影片资料备份中；账号范围仍仅在整站备份中。
- 电影封面保持直接播放。电视剧（含共 1 集）封面只打开详情，不自动播放。详情选集为编号方格，选中高亮，选好后点“播放”；网页播放器也提供编号方格，可点其他集切换。没有会员角标，手机 4 列、宽屏 6 列，较长剧集列表可滚动。
- 内部保留不可见的线路选择控件，仅供旧 App 折叠屏原生“下一集”控制使用；电视剧界面不显示下拉菜单。电影多线路选择不受影响。不提供自动连播或服务器转码。

## 手动上传演员头像（1.6.1）

管理员登录后，在右侧“演员列表”点击演员，在主列表上方的大头像旁点击“上传演员头像”。支持静态 JPG、PNG、WebP，最大 5 MB、最长边 8192 像素。普通用户只能浏览有权限影片关联的头像，不能上传。

同名演员跨片库共用手动头像；不改 NAS 原图或 NFO，重扫不会覆盖。“恢复资料头像”只撤销本站上传的覆盖。文件在 data/actors，关系在 data/library.json，整站备份及网页影片备份均包含手动头像。网页影片备份仍不含账号。

Android 1.2.2 新增系统文档图片选择器，需安装新 APK；仅重新加载旧 App 不能获得原生文件选择器。本版未真机验证各文档提供器、折叠状态及第三方播放器。
