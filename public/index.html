服务与网络设置

IPv6 默认关闭；仅本机时增加 [::1]，允许网络访问时增加 IPv6 网络监听。两个协议使用相同端口，保存后手动重启。

仅本机时监听 127.0.0.1（启用 IPv6 时另监听 ::1）；允许网络访问时监听所有 IPv4 接口，启用 IPv6 后还监听所有 IPv6 接口，可能包括 VPN / 公网地址。公网 IPv6 可能无需端口映射即可被访问。HTTP 不加密，只在可信网络使用；本程序不修改防火墙。

当前访问地址

IPv6 地址需保留方括号。不为 fe80:: 链路本地地址生成链接；跨设备请使用 ULA 或全局 IPv6 地址。保存后请在服务管理面板中重启。正在观看的视频会在手动重启时中断。若端口被占用或系统不支持 IPv6，启动时会报错并停止全部监听；PORT 环境变量会优先于页面中的端口设置。

网站运行控制

01 / 连接 NAS
在资源管理器打开 NAS 共享文件夹并完成登录，或把共享映射为网络驱动器，再填写如 Z:\电影 或 \\192.168.1.20\movies。本网站不保存 NAS 登录密码，也不主动挂载系统驱动器。

        
02 / 海报、文件夹归档与影片类别
读取 poster.jpg、folder.jpg、cover.jpg 或 片名-poster.jpg；背景图支持 fanart.jpg。同名 .nfo 或 movie.nfo 可提供剧情、类型、评分和演员。
片库/
├─ 电影/
│  └─ 星际穿越.2014.mp4
└─ 剧集/
   └─ 电视剧名称/
      ├─ tvshow.nfo
      ├─ 第1集.mp4
      └─ 第2集.mp4
按「片库 / 归档分类 / 电视剧名 / 视频文件」识别电视剧，详情显示集数和选集；普通电影放在根目录或一级目录。重新扫描可自动读取常见 MP4/MOV/MKV/WebM 时长，悬停封面右下角显示。资料缺失保持空白。
文件夹名称只用于独立的归档分组，不是影片类别。管理员在详情或网页播放页点击「编辑类别」自行填写、修改或清空。NFO / API 可以提供初始资料类别；你的手动设置优先，重扫不会覆盖。

        
03 / 在线补全电影资料
添加 TMDB Read Access Token 后，仅保存即可；在 NAS 影片详情里选择「匹配资料」，确认影片后导入封面与分类。搜索会向 TMDB 发送片名，不会上传视频或 NAS 路径。未联网时仍可使用已扫描的资料和本地海报。

        
04 / 播放与安全
MP4 / WebM 通常可直接播放，实际取决于编码。MKV、AVI、HEVC、DTS 和部分 HLS 可能不受浏览器支持；本版不含转码，可在左下角「设置 → 播放器设置」选择本机播放器，或先转为 H.264 + AAC MP4。不加载外部解析网站。
默认仅监听本机 127.0.0.1；管理员可在图形化后台配置端口与网络访问，保存后重启生效。管理员可查看用户登录活动并管理来源与调试令牌；普通用户独立保存收藏、进度与设置。不要直接暴露到公网。移除来源只删除片库索引，不删除 NAS 原文件。扫描为手动触发，不含后台自动监控。
